# Mozc に大規模辞書を足すと変換は良くなるのか — 実測

拡張辞書プロジェクトは長らく「収録語数」で語られてきました。しかし、語数が増えれば
変換が良くなるとは限りません。本稿は、26.7万語の辞書を Mozc に追加した際の効果を
実測した記録です。

結論を先に書きます。

1. **日常語の変換精度は、改善しませんでした**（第1候補一致 87.1% → 85.5%）。測定値は2件下がりましたが、この差は統計的にゼロと区別できません
2. **理由は、Mozc 単体で既に上位10件のカバー率が 100% だったから**です。追加辞書が
   入り込む余地がありません
3. **失敗はすべて「順位の問題」で、語彙の問題は1件もありませんでした**。正解は
   2〜3位に存在しており、これは辞書では直せません（学習で直ります）
4. **辞書の 48.5% は Mozc が元から出せる語**でした。競合を増やすだけです

---

## 測定条件

| 項目 | 値 |
| :--- | :--- |
| IME | Mozc 3.33.6089.100 (Windows) |
| 辞書 | UniDic 2025-12（CWJ + CSJ）由来、267,413 語、人名を除く |
| テストセット | 語単位 124 件 / 8 カテゴリ（手書き） |
| 判定 | 変換後の第1候補が期待表記と一致するか |

測定は稼働中の `mozc_server` へ名前付きパイプで接続し、実際に変換させています。
辞書の ON/OFF は `user_dictionary.db` を空の辞書へ差し替えて `RELOAD_AND_WAIT` を
送ることで行いました。利用者の学習履歴（`history.db`）が効いた状態での実測です。

---

## 結果1: 変換精度は上がらなかった

| 指標 | 辞書なし | 辞書あり | 差 |
| :--- | ---: | ---: | ---: |
| 第1候補一致 | 108 / 124 (87.1%) | 106 / 124 (85.5%) | **−2** |
| 上位10件に含む | 124 / 124 (**100%**) | 122 / 124 (98.4%) | **−2** |

改善 1 件、悪化 3 件。

> [!IMPORTANT]
> **この −2 を「悪化した」と読むべきではありません。** 結果が変わったのは4件だけで、
> McNemar 検定にかけると p ≈ 0.63。統計的にゼロと区別がつきません。
> この測定が言えるのは「悪化した」ではなく**「改善は検出できなかった」**です。
>
> なお他の結果 — 上位10件カバー率100%（124/124）、失敗16件が全て2〜3位、
> 重複率48.5%（26.7万件の全数調査）— はいずれもこの問題を持ちません。

```
改善  せっしょう  期待=摂政    なし=殺生      あり=摂政
悪化  かなづかい  期待=仮名遣い なし=仮名遣い  あり=かな遣い
悪化  しょうえん  期待=荘園    なし=荘園      あり=勝縁
悪化  やまもと    期待=山本    なし=山本      あり=山元
```

注目すべきは**辞書なしの上位10件カバー率が 100%** である点です。Mozc は日常語に
関して、既に全問の正解を候補として持っていました。追加辞書にできることは、
既存の順位を乱すことだけです。

## 結果2: 失敗は100%が順位の問題だった

Mozc 単体で外した 16 件について、期待表記が何位にあるかを調べました。

| 区分 | 件数 |
| :--- | ---: |
| 1位（正解） | 108 |
| 2〜3位 | **16** |
| 4位以下 | 0 |
| 圏外（語彙が無い） | **0** |

**圏外はゼロでした。** 語彙が足りないケースは1件もなく、すべて「正解は持っているが
1位に出せていない」状態です。

順位の問題は辞書では直せません。直すのは学習です。実際に確認しました。

```
学習前: 1位=校正  「構成」は2位
     ↓ 一度「構成」を選んで確定する
学習後: 1位=構成  「構成」は1位
```

一度選ぶだけで固定されます。16 件を修正すれば 124/124 になります。

## 結果3: 辞書の半分は重複登録だった

辞書の全 267,413 件を Mozc に通し、ユーザー辞書なしでも上位10件に出るかを
調べました（所要 68 分）。

| 分類 | 件数 | 割合 |
| :--- | ---: | ---: |
| Mozc が元から出せる | 129,753 | **48.5%** |
| **Mozc が上位10件に出せない** | **137,660** | **51.5%** |

約 13.8 万語は、Mozc が持っていない語です。

ただし、この全件走査で調べたのは辞書なしの Mozc だけです。辞書を入れたときに上位10件に
届くかは、辞書から 2,000 件を無作為に抜き出し、辞書あり・なしの両方で変換して別に
測りました（`measure_coverage.py`）。

| 分類 | 割合 |
| :--- | ---: |
| 既存（辞書なしでも上位10件に出る） | 51.0% |
| 追加（辞書を入れて初めて上位10件に出る） | 45.7% |
| 未達（辞書を入れても上位10件に届かない） | 3.2% |

Mozc が出せない語の中にも、辞書に載せても上位10件に届かない語（未達）があるということ
です。実際に変換を増やしているのは「追加」の語で、これは実在する貢献です。なお既存の
割合が全件走査の 48.5% より高いのは、抜き出した 2,000 件の偏りです（同じ 2,000 件を
全件走査の結果と照らしても 1,021 件 = 51.0% が既存でした）。

品詞別に見ると、価値の偏りが大きいことが分かります。全件走査の結果を品詞ごとに
数えたものです。

| 品詞 | 件数 | Mozc に無い割合 |
| :--- | ---: | ---: |
| アルファベット（`MVP` `CFA` `Gesellschaft` `ぐらむ→g`） | 6,019 | **95.1%** |
| 動詞（サ行五段） | 5,597 | 59.4% |
| 名詞 | 158,907 | 51.1% |
| 地名 | 25,679 | 41.7% |
| 名詞サ変 | 15,428 | **34.0%** |

「Mozc に無い割合」は、その品詞の語のうち、辞書なしの Mozc が上位10件に出せなかった
語の割合です（2,000 件の抜き出しで測った「追加率」とは別の値で、そちらは未達を含まない
ため低く出ます。例: アルファベット 93.8%、名詞サ変 28.0%）。

`アルファベット` は Mozc がほとんど持っておらず、`名詞サ変` は3分の2が重複でした。

## 拡張辞書を作る人にとっての含意

**1. 語数は品質の指標になりません。**
26.7 万語のうち、Mozc が元から出せない語は 13.8 万語（51.5%）でした。実際に変換を
増やしたのはその大半で、一部は辞書を入れても上位10件に届いていません（結果3）。残りは
競合を増やすだけです。「◯◯万語収録」は、その半分が無意味かもしれません。

**2. 日常語での改善は期待できません。**
Mozc の系辞書は日常語に関して既に十分です（上位10件カバー率 100%）。改善余地が
あるのは、標準辞書に載っていない領域だけです。

**3. 狙うべきは「穴」であって「網羅」ではありません。**
測定では `アルファベット`（略語・外来語・単位記号）が最も価値が高く、`名詞サ変` は
3分の2が重複でした。全部入れるより、非収録率の高いスライスに絞るほうが強くなります。

**4. 語を足すと順位が乱れます。**
語を足すと同音候補が増え、正しい候補が押し下げられます。本測定では1読みあたり
平均 8.2 件の候補が追加されていました（同音異義語カテゴリでは 24.9 件）。

**5. 利用者の体感を左右するのは学習です。**
辞書は語彙の穴しか埋められません。順位は学習が決めます。日常の変換体験を
改善したいなら、辞書ではなく学習機能の活用が本筋です。

## 再現方法

測定に使ったスクリプトは [`eval/`](../eval/) にあります。**任意の Mozc ユーザー辞書に
使えます** — 本プロジェクトの辞書に限りません。

```bash
pip install grpcio-tools
python eval/fetch_mozc_protos.py

# 変換精度の A/B（対象辞書を Mozc にインポートした状態で）
python eval/measure_conversion.py --testset YOUR_TESTSET.tsv

# 辞書のうち何割が Mozc に無い語か
python eval/measure_coverage.py YOUR_DICT.tsv -n 2000
```

詳細は [`eval/README.md`](../eval/README.md) を参照してください。

## 限界

- Mozc 3.33.6089.100 の1バージョンでの測定です。他バージョン・他IMEでは異なりえます
- テストセットは手書きの 124 件で、**語単位**です。文単位の変換は測っていません
- 1台の環境・1人の学習履歴の状態での測定です
- 124件という標本サイズでは、数件程度の精度差は検出できません
- 「Mozc が出せる」の判定は上位10件に含まれるかで行っています。この基準は
  「10位以内にはあるが1位ではない」語を重複と見なすため、順位改善の効果を
  過小評価します
