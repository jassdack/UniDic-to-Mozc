> [!IMPORTANT]
> **v1.1.0 は 2026-09-07 にアセットを差し替えています。**
>
> 公開当初（2026-09-06）の v1.1.0 は **354,666 語・4分割**で、人名を含んでいました。
> 差し替え後は **267,413 語・1ファイル**（人名は別配布）です。差し替え前の
> ダウンロードは 4 件でした。
>
> 差し替えの理由は3つあります。
>
> 1. 人名 87,253 語が同音異義語の候補を大きく圧迫していた。実測で、除外しても
>    カバレッジは 1 件も落ちず、競合だけが約 25% 減ることを確認した
> 2. 「Mozc のユーザー辞書は1ファイル最大10万語」という前提が誤りだった。
>    実際の上限は 1,000,000 語で、分割は不要だった
> 3. 「CWJ と CSJ の統合による語彙の拡充」という説明が誤りだった。両者の語彙は
>    完全に同一で、異なるのは単語生起コストの値のみだった
>
> 経緯と実測値は [`eval/README.md`](../../eval/README.md) を参照してください。

## 更新手順

リリース本文を変更したら、このディレクトリの内容も合わせて更新してください。

```bash
gh release view vX.Y.Z --json body --jq '.body' > docs/releases/vX.Y.Z.md
gh release edit vX.Y.Z --notes-file docs/releases/vX.Y.Z.md
```
