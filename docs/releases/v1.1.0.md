国立国語研究所が公開しているコーパス「UniDic (2025-12版)」の語彙 約102万語を Mozc (Google 日本語入力) 向けに変換し、**267,413語の実用的な基本形**として整理したユーザー辞書データです。

> [!IMPORTANT]
> **2026-09-07 に本リリースのアセットを差し替えました。**
> それ以前にダウンロードされた方は内容が異なります（354,666語・4ファイル → **267,413語・1ファイル** ＋ 人名辞書を分離）。
> お手数ですが再ダウンロードのうえ、辞書ツールで既存の UniDic 辞書を削除してから入れ替えてください。

## 主な変更点

### 1. 人名 87,253語を既定辞書から分離しました

同音異義語の候補を大きく圧迫していたため、人名を既定辞書から外し、別配布としました。

判断は推測ではなく**実測**に基づいています。利用者が実際に打つ読み124件に対して、辞書が注入する候補を測定しました。

| 指標 | 従来（人名込み） | **本リリース（人名なし）** |
| :--- | ---: | ---: |
| 語数 | 354,666 | **267,413** |
| 1読みあたり平均競合数 | 11.0 | **8.2** |
| 同音異義語での競合数 | 31.1 | **24.9** |
| 注入1件あたりの有用率 | 8.5% | **11.4%** |
| 期待表記をカバーできた読み | 116 / 124 | **116 / 124** |
| 分割ファイル数 | 4 | **1** |

**カバレッジは1件も落ちていません。** 主要な姓は地名・固有名詞としても収録されているためです。

```
たなか/田中 : 人名, 地名          すずき/鈴木 : 人名, 固有名詞
やまもと/山本: 人名, 地名, 名詞    こばやし/小林: 人名, 地名
```

一方で**地名は分離していません**。「大阪」「京都」「横浜」「札幌」「秩父」は品詞「地名」でしか収録されておらず、外すと語彙そのものを失うためです。

副次的に、`(読み, 表記)` が重複するエントリが 9,715件 → 2,941件（−70%）に減りました。

### 2. 品詞フィルタを変換スクリプトに追加しました

```bash
python converter_scripts/merge_unidics.py --exclude-pos 人名 ...   # 除外
python converter_scripts/merge_unidics.py --only-pos    人名 ...   # 抽出
```

### 3. 辞書が1ファイルになりました（インポート3回 → 1回）

これまで「Mozc のユーザー辞書は1ファイル最大10万語」という前提で分割配布していましたが、**この前提は誤りでした**。

Mozc のソースを確認したところ、1辞書あたりの上限は **1,000,000 語**です。

```cpp
// src/dictionary/user_dictionary_storage.cc
constexpr size_t kMaxDictionarySize = 100;    // 辞書の「個数」の上限
constexpr size_t kMaxEntrySize = 1000000;     // 1辞書あたりの語数の上限
```

インポート経路も同じ上限を使い（`user_dictionary_importer.cc`）、GUI辞書ツールに追加の語数制限はありません。Mozc 3.33.6089.100 へ 267,413 語を1ファイルでインポートできることを実機でも確認しました。

**この結果、インポート操作が3回から1回になりました。**

### 4. 品質測定の仕組みを追加しました

`eval/` に測定スクリプトを同梱しました（外部依存なし）。上記の数値は誰でも再現できます。

```bash
python eval/measure_injection.py mozc_unidic_merged_?.tsv
```

## 訂正: CWJ と CSJ の統合について

これまで「CWJ と CSJ の統合による語彙の拡充」と説明していましたが、**これは誤りでした**。実測の結果、両者の語彙は完全に同一です。

```
CWJ 語彙数: 354,666    CSJ 語彙数: 354,666
共通      : 354,666    CWJ のみ: 0    CSJ のみ: 0
共通語のうちコストが相違: 354,653
```

両者が異なるのは単語生起コストの値のみで、UniDic の CWJ 版と CSJ 版が共通の語彙素データベースを共有しているためです。統合の効果は語彙の増加ではなく、書き言葉・話し言葉の双方の統計を踏まえたコスト値の採用（＝同音候補の並び順）にあります。

## 既知の弱点

短単位（SUW）辞書であるため、**複合語は収録されていません**。測定でも「構造体」「非同期」「再帰的」「古文書」「万葉仮名」「廃藩置県」などが引けないことを確認しています。

## 導入手順

1. `mozc_unidic_merged_v1.1.0.zip` をダウンロードして解凍します。
2. Mozc（Google 日本語入力）の「辞書ツール」を開き、「管理」>「新規辞書にインポート」から `mozc_unidic_merged_1.tsv` を指定します。**1ファイルだけです。**
3. 人名が必要な方は `mozc_unidic_names_v1.1.0.zip` を**別の辞書として**追加インポートしてください。分けておくと、変換候補が煩雑に感じたときに一括で無効化できます。

> [!NOTE]
> 旧版からアップデートする場合は、辞書ツールで既存の UniDic 辞書を削除してから再インポートしてください。収録内容が変わっているため、上書きではなく入れ替えが必要です。
