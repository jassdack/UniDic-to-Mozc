国立国語研究所が公開している最高峰のコーパス「UniDic (2025-12版)」の語彙 約102万語を Mozc (Google 日本語入力) に最適化させ、**約35.4万語の実用的な基本形**へと統合・昇華させたユーザー辞書データです。

### 特徴
* **ビルド不要**: C++コンパイラやBazel等の環境構築は一切不要です。（ファイルを選ぶだけ）
* **品質の担保**: サジェスト汚染を防ぐため、記号・顔文字・不要な口語活用などを完全に排除・整理済み。
* **クリーンなライセンス**: 辞書データは「修正BSDライセンス」で利用可能なため、安全に運用できます。
(ライセンスの詳細については同梱のテキストファイル、ならびに国立国語研究所のWebサイトをご確認ください。)

### 収録データ (ソース)
* 現代書き言葉UniDic (UniDic-CWJ) 2025-12_full
* 現代話し言葉UniDic (UniDic-CSJ) 2025-12_full

### 導入手順
1. 下記の `Assets` から、**`mozc_unidic_merged_v1.0.0.zip`** をダウンロードして解凍してください。
2. その中に分割された4つのファイルが入っています。
3. Mozc（Google 日本語入力）の「辞書ツール」を開き、「管理」>「新規辞書にインポート」から4つのファイルをそれぞれ順番にインポートしてください。
   *(※「1辞書につき最大10万語まで」というMozcの制限を回避するため、必ずすべてのファイルをインポートしてください)*

詳細な技術仕様や、自分でPythonスクリプトを回してカスタマイズしたい方は [Project.md](https://github.com/jassdack/UniDic-to-Mozc/blob/main/Project.md) をご覧ください。
